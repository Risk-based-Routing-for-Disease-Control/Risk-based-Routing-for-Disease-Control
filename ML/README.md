# ML

`감염농장_전처리.ipynb`가 만든 시/도별 농장현황·감염농장(`data/{시/도}/농장현황/`, `data/{시/도}/감염농장/`)에서, 발생일 기준 시간 윈도우의 농장현황만 추출해 ML 학습용 데이터셋을 만드는 폴더. **감염농장과 조인하지 않고 농장현황만 추출**하며, 출력에는 라벨이 없다.

## 실행 순서

```
1. ML_농장현황_전처리.ipynb  (PROVINCE 변수만 바꿔 시/도별 반복 실행)
   -> ML_{PROVINCE}_농장현황_1year.csv
   -> ML_농장현황_건수.csv (시/도별 건수 누적)
2. ML_merge_전국.py
   -> ML_전국_농장현황_1year.csv
```

`감염농장_전처리.ipynb`를 먼저 같은 `PROVINCE`로 실행해 `data/{PROVINCE}/농장현황/`, `data/{PROVINCE}/감염농장/`을 만들어둬야 한다.

## ML_농장현황_전처리.ipynb -> ML_{PROVINCE}_농장현황_1year.csv

1. **시간 윈도우 추출**: 그 시군에 감염농장이 발생한 날짜마다, 발생일 기준 **±1년** 범위의 농장현황 행만 모은다. 감염농장이 여러 건이면 윈도우가 겹쳐 중복이 생기므로 시군명·농장명·상세구분·소재지지번주소·위도·경도·사육두수가 같으면 중복 제거.
   - 노트북 안의 안내 문구(마크다운, print 로그)는 "±6개월"이라고 적혀 있지만, 실제 코드(`pd.DateOffset(years=1)`)는 ±1년 윈도우를 사용한다. 출력 파일명의 `_1year` 접미사가 실제 동작과 맞는 쪽이고, 텍스트가 과거(±6개월이던 시절) 문구를 못 지운 채 남아있는 상태다.
2. **닭/오리 세부분류 정규화**: 시/도마다 `축종명`/`상세구분`에 세부 항목(육계·종계·산란오리 등)이 들어가는 위치가 달라서, 루트 `livestock_codes.csv` 어휘 기준으로 닭/오리 관련 단어를 찾아 `축종명`을 닭/오리로, `상세구분`을 표준 세부값으로 통일한다.
   - 한 행에 표준 세부값이 두 개 들어있으면(예: 종계+산란계) 임의로 하나를 버리지 않고 `/`로 합쳐서 보존.
   - 닭/오리가 섞였거나 닭·오리가 아닌 축종과 섞인 행은 원본 데이터 자체의 모순이라 보고 원본 값을 그대로 둔다.
3. **컬럼 통일**: `시군명, 농장명, 축종명, 상세구분, 사육두수(마리), 소재지지번주소, WGS84위도, WGS84경도, 조사날짜` 9개로 고정 (경기도에만 있는 소재지우편번호/소재지도로명주소/데이터기준일자/비고는 제외).
4. **저장**: `ML_{PROVINCE}_농장현황_1year.csv`로 저장하고, `ML_농장현황_건수.csv`에 해당 시/도 건수를 갱신(다른 시/도 행은 유지).

## ML_merge_전국.py -> ML_전국_농장현황_1year.csv

`ML_*_농장현황_1year.csv` 파일들을 모두 모아 9개 표준 컬럼만 골라 맨 앞에 `시도명` 컬럼을 붙여 합친다. 시/도별 노트북을 새로 돌릴 때마다 다시 실행해서 기존 파일을 덮어써야 한다.

이 출력은 `KMA/match_farm_weather.py`가 농장별 날씨를 붙이는 입력으로 쓰인다 (`KMA/README.md` 참고).

## 윈도우 크기가 다른 두 버전

ML 학습용으로 윈도우 크기가 다른 두 데이터셋을 같이 보관한다.

- `ML_{시/도}_농장현황.csv` / `ML_전국_농장현황.csv`: 발생일 기준 **±6개월** 윈도우, `coord_precision`(좌표 정밀도) 컬럼 포함
- `ML_{시/도}_농장현황_1year.csv` / `ML_전국_농장현황_1year.csv`: 발생일 기준 **±1년** 윈도우

현재 노트북(`ML_농장현황_전처리.ipynb`)은 `_1year` 버전만 생성한다. `±6개월` 버전은 노트북이 그 윈도우를 쓰던 시점의 출력이 남아있는 것으로, 다시 만들려면 노트북의 `pd.DateOffset(years=1)`을 `months=6`으로 되돌려 실행해야 한다. `ML_merge_전국.py`도 `_1year` 파일만 globbing하므로, `±6개월` 버전의 전국 통합 파일(`ML_전국_농장현황.csv`)을 갱신하려면 별도로 만들거나 스크립트를 두 버전 다 처리하도록 고쳐야 한다.
